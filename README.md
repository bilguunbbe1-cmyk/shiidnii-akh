# ШИЙДНИЙ АХ — Airbum · Ball is life

Улаанбаатарын хорооллын шийд бүрээр явдаг streetball цуврал **«Шийдний ах»**-ын вэбсайт.

## Санаа

- **Шид!** Hero хэсэгт бөмбөг шидэж оноо цуглуулна. Swish, brick, дараалан онох, «ON FIRE» бүгд байгаа. Space товчоор ч шидэж болно.
- **Шийдний газрын зураг.** Цуврал бүр хотын өөр шийд дээр болдог тул Улаанбаатарын схем зураг дээр 14 шийдийг тэмдэглэсэн. Цэг дээр дарахад тэнд болсон дугаарууд гарч ирээд сайт дотроо тоглоно.
- **LED скорборд.** Нийт дагагч, үзэлт, дугаар, шийдийн тоо, 24 секундын шот цагтай.
- **Мэдээний гүйдэг мөр, тоглогчийн карт маягийн цуврал, TikTok highlight клипүүд, 4 платформын сошиал статистик.**

## Тоо шинэчлэх, дугаар нэмэх

Бүгд `js/data.js` дотор байна:

- `SOCIALS` — дагагч, like, пост
- `VIDEOS` — шинэ YouTube дугаарыг эхэнд нь нэмнэ. `map` талбарт шийдийн id-г бичвэл газрын зураг дээр автоматаар гарна
- `MAP_SPOTS` — шийдүүдийн байрлал (x, y нь 1000×620 схем дээрх ойролцоо цэг)
- `CLIPS` — TikTok клипүүд

## Технологи

HTML, CSS, цэвэр JavaScript. Framework болон build алхам байхгүй. Фонт: Google Fonts (Oswald, Rubik, Share Tech Mono). YouTube видео, thumbnail-уудыг YouTube-ээс шууд ачаална.
